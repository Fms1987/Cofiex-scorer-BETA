# data/cases_anonymized.csv

One row per **avaliação** (a pleito at a meeting), meetings 165–185. Regenerated by `tools/build_cases_from_fichas.py` from `fichas/`.
Opaque ids: `case_id` = avaliação ficha id, `pleito_id` = pleito ficha id (same ids as the files in `fichas/`).

| Column | Meaning |
|---|---|
| regime, year, quarter, attempt, attempts_total | Res. 17/2021 (`R17_2021`) or Res. Normativa 1/2024 (`NR1_2024`); meeting year and quarter; attempt number of the pleito |
| subtype, ticket_band | Federal / Subnational–General / PPP / Fiscal / …; loan band USD (`<50M … >400M`). `BRL-nominal` = amount column held reais, not converted |
| lender, lender_check | Creditor, **verified against the CC text** (`match`, `mismatch` → value taken from the CC, `undetermined`) |
| counterpart_pct, counterpart_check | Counterpart share, verified against the CC when the CC prints both amounts |
| sector, sector_source, sector_secondary | `verified` = read from indicators/components (filled narratives); `keyword_heuristic` otherwise (less reliable) |
| outcome, reason_cat | approved / not_approved / withdrawn; normalized non-approval reason |
| ae, idh_pts, capag_pts, debt_pts, total | Workbook scores (components only for NR1_2024; R17 rows carry the total) |
| total_published | Score printed in the official meeting result when the workbook is blank |
| nt_available, nt_match, nt_docs | NT availability, how it was linked (`same_meeting`, `no_meeting_folder`, `single_attempt_fallback`, `none`) and number of distinct NT documents |
| n_indicators, n_indicators_parse, baseline_defined_share, baseline_with_year_share | Indicator count (`verified` by the narrative step, else heuristic) and baseline shares (rule v3: a stated value counts; unexplained zero does not) |
| mentions_* | 0/1 keyword flags from the CC text |
| tags | Controlled-vocabulary tags (extras live in the pleito ficha as `tags_extra`) |
| narrative | `filled`, `pending` or `no_cc_text` |

Removed on purpose: proponent, project title, PFE/SEI/CC numbers, meeting number, exact date, state/municipality.
Known gaps: 43 avaliações have no CC text; 13 NR1 avaliações with a blank workbook score had no printed score to recover.
